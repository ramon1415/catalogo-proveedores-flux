# Pantalla de Disponibilidad Presupuestal

Archivos incluidos:

- `presupuesto.html`
- `presupuesto.js`

## Cómo subir a GitHub

1. Entra al repo `catalogo-proveedores-flux`.
2. Usa `Add file > Upload files`.
3. Sube `presupuesto.html` y `presupuesto.js`.
4. Haz commit.
5. Vercel hará deploy automático.

## URL esperada

Después del deploy, abre:

`https://catalogo-proveedores-flux.vercel.app/presupuesto.html`

## Importante

Si la pantalla abre pero no muestra empresas, partidas o disponibilidad, probablemente faltan policies RLS para lectura desde el frontend.
